# UFi Research — V5 homepage and Services prototype

## Upload and preview

Upload the ZIP contents into a new V5 folder in your test GitHub Pages repository. Home and Services link locally using relative URLs; no build, CNAME, new dependency or automated deployment is included. For local preview, run `python -m http.server 8000` inside this folder and open http://localhost:8000. Stop with Ctrl+C.

About, Contact and Playtest continue to the existing live pages. Contact links lead to the existing Web3Forms page, whose integration is unchanged. Services remains a focused design prototype, not a complete migration of all FAQs and package details.

## This revision

- Restored the V3 “How we work / We test. You keep creating.” section, including the three steps. The homepage now progresses from identity to introduction, process, then research insights.
- Kept the simpler introduction, approved article card, logo-and-tagline hero and intentional gradient reversal. No stars, team photos or Launchpad references on the homepage.
- Removed the alien image and its asset from Services and the package.
- Applied navigation cues from the supplied portfolio reference: simple desktop link underlines, distinct current-page underlines, and background highlights across mobile dropdown links. The Playtest pill uses a muted-purple background and rose border on hover or keyboard focus, with no underline.
- Kept the article's expandable concept unchanged. Full-card lift effects are reserved for future article/case-study cards with actual destination links; applying them to a non-link surface would suggest an unsupported action.

PlaytestCloud was also reviewed for content and layout inspiration. The Services deliverables explanation is more concrete as a result, using capabilities already described on UFi’s existing Services page. No competitor statistics, customer logos, turnaround promises, platform features or copy were imported.

The supplied portfolio's imagery, personal information, project content and fonts are not included. All source imagery and Open Sans files in this package come from the original UFi materials; the font license is included. The article remains a clearly labeled editorial concept and both pages have noindex directives to remove before eventual production release.
