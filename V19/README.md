## Change

Hero, interior-header and footer textures now share centered horizontal cropping. Below the hamburger-menu breakpoint (56rem / 896px at the default font size), artwork is displayed at 900px wide: half the desktop display size of 1800px, not half the source PNG’s pixel width. Above that breakpoint it uses 1800px, expanding to full width above 1800px. Image aspect ratios are preserved.

Vertical alignment remains center for the hero, top for interior headers and bottom for the footer. Gradients and 15% texture opacity are unchanged. Logo scaling and all other styling/content, HTML, scripts, forms and assets remain unchanged from V18. No form message was submitted.

Reviewed through Personal Web Design, then Universal Design Principles. Offline references cover home/Playtest in both themes at 320px, 390px, 895px, 896px, 1280px and 1920px.
